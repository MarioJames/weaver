# Weaver 品牌素材

![Weaver 珊瑚版品牌组合](weaver-lockup.png)

Weaver 是本地异构 Agent 任务调度控制面：由负责人 Agent 将任务包「编织」并派发给不同引擎的工作代理。

当前采用 **M「珊瑚」**方案。围巾的回环与交叠表达任务之间的连接和编织；尾带左短右长，长尾接近竖直，保留柔和而稳定的轮廓。蜜桃与珊瑚红沿交叉方向自然渐变，搭配暖炭色字标。

尺寸沿用 Convorel 的原图、便携图标与横向组合规格。独立图标额外提供 SVG 封装。只保留这一套定稿，不保留未选方向与多余尺寸。

## 格式与家族关系

图标直接保留选中的原始位图，未重新生成、描摹或重绘渐变。两个 SVG 都内嵌同一张原始 PNG，因此它们是**含位图的 SVG**，图标本身并非纯矢量，不能因文件扩展名为 SVG 就无限放大。

字标沿用 Convorel 的几何字形语言，复用 e、v、r 的路径结构，补齐 W、a；字标没有字体依赖。横向组合以围巾图标为视觉重心，字标可见高度约为图标的七成。正式素材与后台保持同一图文比例，并按各自画布调整外围留白和居中。

| 角色 | 设计参考色 |
| --- | --- |
| 蜜桃 | `#FFB49C` |
| 暖珊瑚 | `#EE7A70` |

图标使用连续的相邻暖色渐变，以上为设计参考色，最终颜色以 PNG 母版为准。搭配 Weaver 的 slate 中性色界面时保留图标暖色，不将其改成界面主色，也不叠加蓝色过渡或阴影。

## 使用

- 按原始比例缩放，不拉伸、旋转或翻转；保留左短右长的结构和透明镂空。
- 独立图标适合白色、浅 slate 等中性背景；已检查浅底、深底及 32 / 64 / 256 px 显示效果。常规使用建议不小于 32 px。
- 文档横向组合自带白底，建议显示宽度至少 240 px。后台使用下述透明组合，不对白底 PNG 抠图。
- 项目文档可直接引用 `docs/assets/brand/weaver-lockup.png`；从仓库根目录引用品牌说明时使用 `docs/assets/brand/README.md`。
- 需要其他尺寸时从 PNG 母版按比例导出；需要调整字标排版时修改组合 SVG。不要从截图或 256 px 图标反向放大生成母版。

## 后台界面

后台展开侧栏及移动端抽屉使用完整的「围巾图标 + 路径字标」，不额外显示普通字体的 Weaver 文本；侧栏收起后只显示图标。界面保留 slate 中性色与 geekblue 操作色。

- [界面组合 SVG](../../../src/renderer/assets/weaver-lockup.svg)：去掉文档组合的白底与外围留白，复用同一组字标路径，内嵌 256 px 图标以控制体积；显示宽度 128 px，透明底适配侧栏。图标可见高度约 24 px，字标约 17 px，以围巾图标为视觉重心。
- [界面图标 PNG](../../../src/renderer/assets/weaver-icon.png)：与本目录的 `weaver-icon-256.png` 字节一致，供收起状态、favicon 与 apple-touch-icon 共用。收起状态固定 24 × 24 px，不随侧栏压缩。

界面素材是同一套定稿的运行时导出。正式横向组合是图文比例的依据；后台导出仅去掉白底、裁剪外围留白并使用较小的内嵌 PNG，不单独改变字标比例。更新品牌时应同步正式素材和界面文件，并检查展开、收起和移动抽屉。

## 来源与验证

方案由内置 imagegen 生成，经用户选定 M「珊瑚」定稿。`weaver-icon.png` 与选中稿的文件字节一致，原图 SHA-256：

```text
e360510bb351b54948ffff2ff3c6a5de5c165a61161c5606a4825a28afe3cef4
```

256 px 图标使用原图经 Lanczos3 缩放并无损压缩；横向 PNG 通过 Sharp / librsvg 渲染组合 SVG 导出。已核对输出尺寸、透明通道、SVG 内嵌原图的一致性、字标路径和本页文件引用，并检查实际渲染效果。
