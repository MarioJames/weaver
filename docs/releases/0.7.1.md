# Weaver 0.7.1

本版围绕 Bot 页面可用性：Bot 聊天支持全部 7 种现有对话引擎（含 DeepSeek Harness），模型与力度沿用各引擎的模型目录与原生合法值；DSH 在 Bot 侧以真实持久 Session 支持多轮，公开正文按原生步骤提交；Bot 启动位置与实际项目目录职责分离；渠道 Tabs 移到配置内容框之外。

## 改进

- **Bot 支持全部 7 种对话引擎**：Claude、Codex、OpenCode、Pi、Grok、Qoder、DeepSeek Harness（dsh）均可在 Bot 页直接选择，直接控制 Bot 聊天，不用创建父 Agent profile，也不覆盖全局 owner/worker 配置。模型从所选引擎的模型目录中选（也可手填），思考力度按各引擎原生合法值选择，切换引擎时自动回退到合法值（DSH 为 off/low/high/max）。
- **DSH 真实持久 Session 多轮**：DSH 每轮以 headless 子进程加持久化 Session 延续上下文，支持多轮追问；公开正文按原生步骤提交时到达，不是逐 token。
- **Bot 启动与项目目录分离**：Bot 启动位置固定为本机 home，仅作待命入口；工作空间列表是任务范围，实际任务按目标项目选择绝对项目目录创建，不把启动位置当默认任务路径。实际派发的工作仍走 Weaver 现有调度并进入任务面板。
- **渠道 Tabs 移出配置内容框**：Bot 页的渠道标签（含飞书）放在配置内容框之外，设置项仍为响应式两列布局，窄屏自动堆叠。

## 已知边界

- DSH 公开正文在原生步骤提交时到达（已提交步骤级），不是逐 token；思考过程、工具调用与状态类事件不进入正文。
- 原生 headless 只有一个主要可写 root（Bot 待命位置）；实际项目工作由 Bot 派发给对应项目的 owner 执行，不在 Bot 对话内直接写项目。
- 手机端流式卡片、选项点击、机器人菜单与多项目派发的真实链路仍待逐项验收；此前版本已完成的只读查询与长连接验证范围以既有历史报告为准，不声称本次已做真实飞书外发验证。

## 升级说明

- 直接替换程序并重启即可，沿用既有配置、凭据、工作空间与历史；排空、备份与回滚建议沿用 0.7.0 说明。
