# Weaver 0.6.0

飞书对话与控制台体验版本：Bot 有了独立页面，飞书里可以直接聊天、点按钮快捷操作；额度、看板、定时任务都更好用了。

## 新功能

- 飞书 Bot 独立页面：聊天渠道和 Bot 设置搬到独立「Bot」页，引擎、模型、思考力度独立选择，不依赖父 Agent 配置。
- 流式对话与快捷操作：飞书里消息逐段回复，卡片带续聊选项和快捷按钮，机器人菜单也能直接触发。
- 6 种对话引擎：飞书对话支持 Claude、Codex、OpenCode、Pi、Grok、Qoder，按需为 Bot 选择引擎、模型和思考力度（OpenCode 填写模型接受的 variant）。
- 多工作空间：Bot 可配置多个本机项目目录，按任务目标在对应目录工作；凭据目录始终不可选。
- 常驻会话与空闲回收：对话会话在 Herdr 中常驻保活，可查看切换；最后一条消息后静默超过配置时长，旧上下文结束并自动建立新会话待命。
- 额度刷新更好懂：OpenCode 登录账号可刷新 Go 套餐窗口，只显示三窗口已用百分比与服务端重置时间（5 小时、每周、每月）；状态是只读参考，不代表模型一定可用，永不自动增删阻断。
- 定时任务卡片化：定时任务改为响应式卡片，桌面多列、手机单列，一眼看清规则与最近运行。
- 任务草稿：新建任务可「存为草稿」，目录和验收标准后补；未命名任务显示目标首行，详情页直接编辑。
- 子 Agent 并发上限：子 Agent 可设并发上限（默认不限），满额时自动跳过或排队。

## 改进

- 看板「新」标识：新出现的任务显示「新」并在所在列置顶一段时间；所有任务卡片支持手动置顶，换列跟随。
- 看板更清爽：看板只放子 Agent 任务，父 Agent 收进筛选栏；Tag 颜色按语义统一，免费渠道有专属标识。
- 待验收提醒：待验收卡片区分父 Agent 是否已确认收到，显示等待时长，超 30 分钟警告。
- 恢复派发更顺手：子 Agent 级解封，子 Agent 页与引擎页都有可见的「恢复派发」；额度耗尽或无解除时间的子 Agent 在调度配置中锁定权重。
- 父子排序免后缀：父 Agent 与子 Agent 均可拖拽排序；ID 不再强制加固定后缀。
- Pi 模型配错早提醒：Pi 启动前核对配置的 `provider/model` 是否在 `pi --list-models` 中存在，缺失时在配置页给出中文原因并拒绝启动，不计入限流。

## 升级说明

- 健康保存不丢上下文：配置无实质变化的保存（或仅调整空闲时长）不会重建会话，只重算回收时间；故障代仍会显式重建以恢复。
- 以下情况会结束旧上下文：空闲超时到期、更换引擎/模型/思考力度或工作空间、显式重建会话（重连、机器人菜单新建会话、启停开关）。
- 多工作空间沿用现有 v2 配置读取，保留凭据、白名单与任务数据；不需要重填凭据，不强制清库。
- 数据库自动升级：相对最新公开版 v0.5.0（schema 9），本版（schema 11）启动时自动顺序执行两步迁移。第 10 步给子 Agent 增加可选并发上限字段（为空即不限，旧库直接可用）；第 11 步清理已下线 zcode 引擎的残留配置（引擎行、子 Agent、父 Agent 引用、阻断与运行状态，含历史策略快照中的同类引用），历史任务原样保留、可照常读取。曾使用 zcode 的配置升级后相关引擎/角色/阻断会被删除，或在失去最后一个可用子 Agent 时被停用，请升级后检查策略；不提供数据库自动回滚，新库用旧版打开会拒绝启动。
